# Translating CasSpeed

The browser interface is currently English-only. Translation support is part of the project requirements; no locale catalog is present yet, so there are no translator credits to list.

When locale catalogs are added, translate user-facing strings while preserving format placeholders, plural forms, HTML attributes, and URLs. Keep product names, protocol names, code, filenames, configuration keys, and literal values unchanged. Include a native-language name and translator credit with each catalog, and verify translated layouts for overflow and right-to-left direction where applicable.
