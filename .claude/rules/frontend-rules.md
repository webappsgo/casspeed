# Frontend Rules (PART 16, 17)

⚠️ **These rules are NON-NEGOTIABLE. Violations are bugs.** ⚠️

## CRITICAL - NEVER DO

- Never ship incomplete, inaccessible, or unstyled server pages.

## CRITICAL - ALWAYS DO

- Implement the required responsive, accessible frontend, admin pages, and API pairs.
- Provide distinct loading, empty, error, and success states; use server rendering.

- Follow the required theme, PWA, security, and page-content rules in the complete PARTs.
