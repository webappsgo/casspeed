# API Rules (PART 13, 14, 15)

⚠️ **These rules are NON-NEGOTIABLE. Violations are bugs.** ⚠️

## CRITICAL - NEVER DO

- Never retain obsolete project endpoints or add compatibility redirects.
- Never return internal errors, stack traces, or sensitive data to clients.

## CRITICAL - ALWAYS DO

- Keep route contracts, schemas, status codes, and content negotiation consistent.
- Implement required health, version, SSL/TLS, REST, Swagger, and GraphQL behavior.

## Key rules

- Pair every user-facing API with its server page and keep route inventories current.
